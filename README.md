# 小小道馆 · 太极一章亲子陪练

面向 5 岁孩子与陪练家长的第一版网页。无需账号，不使用摄像头。

**在线使用：[taekwondo.cheerup.tech](https://taekwondo.cheerup.tech/)** · [GitHub](https://github.com/icandy7272/little-dojang)

![自动检查](https://github.com/icandy7272/little-dojang/actions/workflows/ci.yml/badge.svg)

## 启动

已安装 Python 3 的电脑，在项目目录执行：

```sh
npm start
```

也可以不使用 Node，直接运行：

```sh
python3 -m http.server 4387 --bind 127.0.0.1
```

打开 http://127.0.0.1:4387 。请通过本地服务打开，直接双击 HTML 文件不能加载模块。

## 已实现

- 太极一章四段慢练，涵盖 18 拍；第 14、16 拍同时包含前踢和落地冲拳。
- 默认使用 B 站中文字幕示范，支持指定时间起播和重播；本段结束需手动暂停，倍速在视频内设置。
- 可选 YouTube 官方示范或本地视频，支持到结尾自动暂停、循环和慢放。
- 看示范、一起练、自己试三种模式；独立尝试时先隐藏示范和动作提示。
- 每段中文记忆口令、逐拍分解、朝向、家长关注点、辅导方法和鼓励示例。
- 口令朗读（依赖设备浏览器语音能力）。
- 记录独立完成、需要提示、再练一练；记录提示次数和备注；今日进度、练习历史、撤销最近记录。
- 打印当前段或全套四段陪练卡。
- 本地视频选择及每段时间设置，用于无法访问 YouTube 的环境。

## 视频使用说明

默认使用 [B 站中文字幕版](https://www.bilibili.com/video/BV1u2421M7EE/)，UP 主「嘻嘻嘻滚啊」发布，并非国技院官方账号。使用 B 站站外播放器，不下载、不转存、不向 GitHub 添加视频文件。第一段 9:57 已通过浏览器核对。切换段落会重新从该段开始播放；切到「自己试」或点击「暂停并收起」会卸载播放器停止播放。

B 站接入当前不能从本页精确控制播放结束和循环，因此显示手动暂停时间，倍速使用视频内的控件。「视频来源 / 设置」可以切换到 YouTube 或本机视频。


官方视频：[KUKKIWON WORLD TAEKWONDO HEADQUARTERS · TAEGEUK 1JANG](https://www.youtube.com/watch?v=WhkjRruCBTo)。应用通过原平台嵌入播放，不重新分发视频。

| 分段 | 拍数 | 默认慢练片段 |
|---|---|---|
| 下格挡与冲拳 | 1–6 | 9:57–10:15 |
| 中格挡与冲拳 | 7–12 | 11:53–12:08 |
| 上格挡、前踢、冲拳 | 13–16 | 13:16–13:32 |
| 下格挡与收尾 | 17–18 | 14:37–14:47 |

章节入口根据官方视频公开转写核对。边界可在“换成本地视频”里的分段设置中微调。若平台限制嵌入，使用“在原平台打开本段”。

本地视频只在设备上播放，不上传；刷新页面后需重新选择。每段起止时间保存在浏览器中，与官方视频的时间分开。选择整套教学视频时，为四段分别设定起止时间。

动作顺序交叉参考：[South Bank Taekwondo 18 拍教学资料](https://sbtkd.com/wp-content/uploads/2022/02/8th-Kup-Complete.pdf)。口令与家长提示是项目自编的记忆辅助，不是官方技术译文；技术细节请教练确认。方向以初始预备姿势为参照，左右以孩子自己为准。

## 记录与隐私

数据仅保存在当前浏览器的 localStorage（`little-dojang-v1`），最多保留 500 次。清理浏览器数据会丢失记录；不同浏览器、设备和访问地址不共享数据。存储失败会显示提示。外部视频由 B 站或 YouTube 提供，口令朗读由浏览器提供。

网页布局适配窄屏；通过部署后的网站地址可在手机和平板上使用。腾讯云发布方式见 [部署说明](deploy/README.md)。

```sh

```

第一段（第 1–6 拍）的“一步一步来”提供原创矢量动作示意图，支持点击放大和打印。绿色标记动作手，文字明确前脚、步型与朝向。图片为侧面完成姿势的记忆辅助，不展示完整转身和起手过程；技术细节请结合示范与教练指导。其余三段暂保留文字分解。
