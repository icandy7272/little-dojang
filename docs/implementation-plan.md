# 太极一章亲子陪练第一版

用户已确认：不使用摄像头，重点是分段示范和家长辅导。

## 设计与实现
- 本地静态网页，无账号、无服务端。响应式，优先家长陪孩子用平板。
- 对应国技院视频的四段：1–6、7–12、13–16、17–18拍；14、16拍包含前踢后冲拳。
- 官方慢练片段：9:57–10:15、11:53–12:08、13:16–13:32、14:37–14:47。章节入口由官方视频公开转写核对，界面注明来源与可调整时间。
- 视频可暂停、重播、循环、慢放。在线用 YouTube IFrame API；不可用时可选择本地视频并为每段设定起止时间。本地文件不上传，刷新后重新选择。
- 四段配独立动作列表、孩子口令、家长观察点、忘记时的辅导方式。
- 看示范 / 一起练 / 自己试模式；自己试默认隐藏提示，可主动查看。
- 家长记录每段独立完成 / 需要提示 / 再练一练，备注、提示次数、本地日期；仅保存在当前浏览器。
- 今日练习建议、练习记录、打印陪练卡。

## 文件与验证
1. tests/core.test.mjs 先测试无效时间、坏数据、记录存储失败和日期隔离。
2. core.mjs 管理分段数据与纯逻辑； app.mjs 管理界面；player.mjs 管理视频。
3. index.html 与 styles.css 提供完整响应式体验。
4. node --test，语法检查，浏览器验证四段切换、模式、进度保存、输入验证、打印与窄屏布局。

## 内容边界
中文口令为记忆辅助，不代替教练技术指导。官方视频为外部嵌入，不下载或重新发布。默认未设置离线视频，用户自行选择有权使用的文件。不给未验证的技术评分或学习速度保证。
